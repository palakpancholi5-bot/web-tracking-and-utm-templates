# Web Tracking, UTM & On-Page SEO Templates

Practical classroom reference templates used in live digital marketing and e-commerce training sessions.

## 1. E-Commerce Campaign UTM Naming Convention
| Parameter | Rule | Example |
| :--- | :--- | :--- |
| `utm_source` | Lowercase platform name | `google`, `meta`, `newsletter` |
| `utm_medium` | Channel type | `cpc`, `paid_social`, `email` |
| `utm_campaign` | Objective + product + month | `sale_kurtis_nov2026` |

## 2. GA4 Key E-Commerce Events Checklist
- `view_item` (Product detail page load)
- `add_to_cart` (Primary CTA click)
- `begin_checkout` (Checkout initiation)
- `purchase` (Thank-you page with `value` and `currency: INR`)

## 3. On-Page SEO Quick Audit Checklist
- **URL Slug:** Short, lowercase, hyphen-separated with primary keyword
- **Title Tag:** 50–60 characters with primary keyword near the front
- **Meta Description:** 150–155 characters with clear value and call-to-action
- **Headings:** Single `H1` per page + structured `H2` subheadings
- **Images:** Descriptive alt text + internal links to relevant pages
